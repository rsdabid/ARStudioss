What ReelPilot does

  • Copies a style. You give it one reel you like. It studies the captions, zooms, graphics, colours and sound effects, then edits your video the same way.
  • Animated subtitles. Bold two-line keyword captions that pop in, coloured like the reference.
  • Animations. Motion graphics such as cards, rating pills, question marks, progress bars and chat bubbles, timed to what you say.
  • Zoom "cuts". Punch-ins and smooth pushes that keep a single take feeling fast.
  • Your B-roll. Put clips in a folder and it places them where they fit. (It doesn't generate AI B-roll.)
  • Colour grade and sound effects. Whooshes, pops and hits on every graphic, plus clean, loud voice audio.

What you need

  • A Mac or Windows computer.
  • Claude Code (recommended), because ReelPilot renders the video on your own computer. Get it at claude.com/claude-code.
  • A raw talking-head video, filmed vertically if possible.
  • One reference reel whose style you want.
💡 You don't need any editing or coding skills. Claude installs the tools, runs everything and asks you before it renders.
ReelPilot v22

1Install the skill

Option A: Claude Code (recommended)

  1. Unzip reelpilot-skill-v2.zip. You'll get a folder called reelpilot.
  2. Move that folder into your Claude skills folder: 
    Mac:      ~/.claude/skills/reelpilot
Windows:  C:\Users\<you>\.claude\skills\reelpilot
    On a Mac, press Cmd + Shift + G in Finder and paste ~/.claude/skills to open it. Create the skills folder if it doesn't exist.
  3. Start Claude Code. Ask it What skills do you have? and check that reelpilot is listed.

Option B: the Claude app

  1. Open Claude → Settings → Capabilities → Skills.
  2. Click Upload skill and choose reelpilot-skill-v2.zip (the zip itself, don't unzip it).
  3. Make sure code execution is turned on.
⚠️ In the Claude app the video is processed in Claude's sandbox, so uploads are limited in size and rendering can be slower. For full-length reels, use Claude Code.

Upgrading from version 1?

Delete the old skill first (remove the old folder, or delete it under Settings → Skills), then install v2. This stops the two versions from clashing.

2Set up your project folder

Make one folder per reel, with these three folders inside:

my-reel/
├── raw/          ← your raw talking-head video
├── reference/    ← ONE reel whose style you want
└── broll/        ← (optional) your own B-roll clips
FolderTips
raw/Use one take. Clear audio gives the best subtitles. If you stumbled a lot, cut the mistakes in CapCut first and put the trimmed video here.
reference/Use only one reel. Pick one with the captions, animations and energy you want. A similar framing (head and shoulders) gives the closest match.
broll/Optional. Screen recordings, product shots, phone clips. Name them clearly (e.g. dashboard.mp4, coffee-shop.mov) so Claude knows what each one shows.
💡 To save a reel you like as a reference, download it from Instagram or TikTok with a saver app or a screen recording, then drop it in reference/.
ReelPilot v24

3Edit your reel

  1. Open Claude Code inside your project folder (in Terminal: cd to the folder, then type claude).
  2. Type:
    Edit my reel with ReelPilot. Raw footage is in raw/, the style reference is in reference/ and my B-roll is in broll/.
  3. First run only: Claude installs ffmpeg and a few Python tools. Say yes when it asks. This takes a few minutes, once.
  4. Claude transcribes your video, studies the reference and shows you a plan: a table of what happens at each moment. Read it and reply "looks good" or ask for changes.
  5. Claude renders a preview sheet of still frames, checks it, then renders the full video. A 30-second reel usually takes a few minutes; longer videos take longer.
  6. Your finished reel is saved as final_edit.mp4 in the project folder, with EDIT_NOTES.md explaining what was done.

Ask for changes in plain words

Make the subtitles bigger.
Cut the pause at 0:12.
Put dashboard.mp4 when I say "my results".
Less zoom, it feels too fast.

Claude only re-renders the part that changed.

Tips & troubleshooting

ProblemWhat to do
Subtitles have wrong wordsTell Claude the correct spelling (names and brands especially). It fixes the captions and re-renders.
Cuts feel offCutting can take a couple of tries. For messy takes, cut in CapCut first, then run ReelPilot on the trimmed video.
"ffmpeg not found"Ask Claude to install it. On a Mac it uses brew install ffmpeg.
A download failed during setupCheck your internet connection and ask Claude to try again. It tells you exactly which step failed.
Edit doesn't look like the referenceUse a reference with similar framing, and tell Claude what's missing, e.g. "the captions in the reference are lower".
Numbers missing from graphicsThat's on purpose. ReelPilot never invents views, prices or stats. Tell Claude the real numbers if you want them shown.

Good to know

  • ReelPilot works on talking-head videos on any topic.
  • It uses your B-roll. It doesn't generate AI footage or download music. If you want music, add your own track and ask Claude to mix it in.
  • Your footage stays on your computer when you use Claude Code.
